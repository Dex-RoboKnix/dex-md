# CLAUDE.md

dex-md: the method, engine and skills dex.md clones at a pinned tag. L2, pre-1.0. See `START.md` for commands.

- `dex.md` stays at or under 300 lines: rules, consent, sign-in check, pinned clones, stage list. Detail goes in `method/`.
- `engine/` is built output plus `install.mjs`. Sources live in `engine/build/`. Modules are pure: no writes, no clock, no network.
- Provenance tags (`PHC`, `OHC`, `AAC`) go in the frontmatter of every markdown spec or doc.
- Public-ready from the first commit: no personal material (no personal legal matter, journals, chat contents, personal email). Run `npm run scan` before every push.
- Commit as the GitHub no-reply address.
- Human authority (Layer 8) overrides any automated decision. Nothing is pushed without the owner's yes.
