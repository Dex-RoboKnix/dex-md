# Use case 6: A part-written thesis

*Illustrative, not a real user.*

**Profile.** A postgraduate with chapter drafts, a reference library, supervisor comments and a git history. The deadline is far off but the structure is unclear.

**Folder kind.** In-flight (`.git` present).

## Why-ladder (invented answers)

| Rung | Answer |
|---|---|
| 5 Procedure | "I want a chapter plan I can finish against." |
| 4 Process | "I write, get comments, then revise." |
| 3 Policy | "Every claim has a source." |
| 2 Principles | "Say only what the evidence supports." |
| 1 Values | "Honest scholarship." |

## Slant

Research and synthesis desk. Evidence: papers, notes, open questions. Wrong if the main blocker is time, not structure. The lens reads Success Criteria as "what the examiner must find".

## Five skills

`SK-GRILL`, `SK-INVENTORY`, `SK-TIMELINE`, `SK-STALL`, `SK-GOALS`.

## Privacy notes

- Unpublished work stays private. Supervisor and peer names become role labels.
- No draft text goes in public docs or issues.

## What done looks like

An inventory of chapters and states, a stall review, a dated plan using only dates the person states, and a folio. The student has confirmed the slant.
