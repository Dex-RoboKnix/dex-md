# Use case 4: A brand-new blank project

**Profile.** Someone has an idea and an empty folder. There is nothing to read, so the person's answers are the whole evidence.

**Folder kind.** Blank: only `dex.md`.

## Why-ladder (illustrative answers)

| Rung | Answer |
|---|---|
| 6 Pattern | "I start reading lists and abandon them within a week." |
| 5 Procedure | "I want a small app that tracks my reading." |
| 4 Process | "I want to try one idea each month." |
| 3 Policy | "Ship something tiny before adding anything." |
| 2 Principles | "Simple beats clever." |
| 1 Values | "Making things I would use myself." |

With nothing in the folder, the ladder matters more: the slant rests on these words alone.

## Slant

App development factory, provisional. Evidence: only the person's answers. Wrong if the idea is really a habit, not a product. Review at the first checkpoint.

## Five skills

`SK-GRILL`, `SK-GOALS`, `SK-RULES`, `SK-PEOPLE`, `SK-INVENTORY` (the last lists what exists, which may be nothing).

## Privacy notes

- Nothing to scan yet. Scan again once files appear.
- Local vault by default. Create a repo only on the person's yes, and keep it private.

## What done looks like

A vault whose nodes hold the person's words, a definition of done, a first small scope, and issues for the first build steps. No node is blank: each holds an answer, `Not applicable: <why>`, or a question.
